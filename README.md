# Tag

This game has been ported to the web and is part of [alris games](https://mrcheesie.github.io/alris_games/). You can play the web version [here](https://mrcheesie.github.io/alris_games/tag/). 

This game was vibe-coded with [Antigravity](https://antigravity.google.com), and was inspired by the Tag game in [Poki](https://poki.com).

A few shortcomings of the Poki tag this fixes:

- Local only; even the web version has no servers and runs entirely on your browser, therefore no internet needed.
- Not banned on the MGIS school WiFi.
- Player 3 (yellow) can jump on the bouncy pad. Did not work in Poki's tag.
- Better music (subjective)
- No ads to unlock the desert map
- No ads in general
- Works on an iPad/tablet/mobile with a keyboard connected. Poki's tag only ever worked on desktop, which was not ideal for students with iPads and keyboards.

## Requirements (to run locally)
- Lua (11.4+)
- [LÖVE2D](https://love2d.org)
